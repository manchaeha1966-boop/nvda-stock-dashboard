# The TSLA Dispatch • 테슬라 1개월 에디토리얼 대시보드

초보자도 이해하기 쉬운 차분한 잡지(Editorial) 스타일의 테슬라(TSLA) 1개월 주식 분석 대시보드 및 리포트입니다.

## 📌 주요 특징
- **에디토리얼 매거진 레이아웃**: 세련된 활자(Newsreader Serif)와 편안한 웜 톤 팔레트를 적용한 잡지 스타일 UI
- **1분 핵심 요약 (Hero Summary)**: 본질, 시세, 핵심 이슈 3대 기둥 요약
- **최근 1개월 종가 차트 (Chart.js)**: 23영업일 일별 종가 인터랙티브 라인 그래프
- **팩트 기반 뉴스 큐레이션**: 공시 및 외신 본문 확인 기사와 유료 결제벽 기사(지어내지 않고 확인 필요 표기) 엄격 분리
- **A4 인쇄 & PDF 내보내기 최적화**: 페이지 중간 잘림 방지(`page-break-inside: avoid`) 및 단독 실행 지원(`stock-report.html`)

## 📂 파일 구성
- `index.html`: GitHub Pages 웹 호스팅용 메인 대시보드
- `stock-report.html`: 외부 의존성(CDN) 없이 오프라인에서도 차트가 동작하는 독립형 인쇄/PDF 리포트
- `chart.umd.min.js`: 차트 구동용 오픈소스 라이브러리
- `tsla_data.json`: 테슬라 23영업일 종가 및 뉴스 메타데이터 원본
- `nvda_data.json`: 엔비디아 비교/참고용 데이터셋
